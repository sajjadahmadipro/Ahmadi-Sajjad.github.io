Overview

A comprehensive Library Management System designed to modernize traditional book keeping. The application handles the entire lifecycle of a library book, from acquisition to member issuance and return.

Key Features

  • Multi-role authentication (Librarian/Member).
  • Late fee calculation engine.
  • Visual dashboard for borrowing statistics.
